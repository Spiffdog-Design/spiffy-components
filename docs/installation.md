# Installation

```bash
npm install @spiffdog/spiffy-components
```

## Peer Dependencies

This library requires the following peer dependencies:

```bash
npm install @spiffdog/spiffy-colors@^2.0.1 \
            @spiffdog/spiffy-hooks@^0.0.11 \
            @spiffdog/spiffy-tools@>=0.3.0 \
            lucide-react@>=0.263.0 \
            react@>=18.2.0 \
            react-dom@>=18.2.0 \
            react-helmet@^6.1.0
```
